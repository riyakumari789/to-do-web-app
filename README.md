# To-Do Web App

A simple and user-friendly To-Do Web App for managing daily tasks.

## Features

- Add new tasks
- Delete tasks
- Simple and clean design
- Responsive layout
- Easy to use

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter a task in the input box.
2. Click the "Add Task" button.
3. The task will appear in the list.
4. Click "Delete" to remove a task.
